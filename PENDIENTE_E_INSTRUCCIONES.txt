ARCADE PRO — LO QUE QUEDA POR HACER E INSTRUCCIONES PARA CONTINUAR (Claude Code)
================================================================================

OBJETIVO
--------
Rehacer en JS + emojis (sin Phaser) todos los juegos de https://emanueleferonato.com/games-covered/ para la
colección Pro (pwa/indexpro.html), con niveles infinitos, animaciones, es/en y soporte TV. Plan: ~14 lotes de 10.
Hechos: lotes 1–7 (90 juegos Pro, ver HECHO.txt).
Pendiente también: demos propias para los juegos de acción, plataformas, un toque, física, estrategia y deportes
(hoy usan la demo genérica, que enseña el control pero no juega bien). Quedan unos 60 títulos (lotes 8–14).

Criterios ya decididos:
· Si varios títulos comparten mecánica se fusionan en un juego (el campo "origin" lista todos los títulos).
· Nombres propios en español (y "title" en inglés), sin personajes ni marcas registradas.
· No se hacen: Boids (no es juego), Educational Game, Line Rider (sandbox), Legends of Runeterra (demasiado grande),
  Knife Hit (ya existe aparte como "Knife Emohit"), Meowdoku (= Emojidoku).
· Táctil SIN cruceta en pantalla; en TV, cruceta/cursor.

INSTRUCCIONES PARA CONTINUAR
----------------------------
Requisitos: Python 3, Node.js, y para las pruebas: pip install playwright && playwright install chromium.

1) Crear un juego nuevo
   · Copiar un juego parecido de herramientas/src/ como plantilla (p. ej. torreta.js = toque simple,
     esquiva.js = arrastrar, gemas.js = tablero, tirachinas.js = física con "// @phys").
   · Estructura obligatoria de cada src/<id>.js:
       // Título|#colorDeTema
       // @phys          ← solo si usa Arcade.Phys (phys.js)
       (function () {
         const { ri, rand, clamp, pick, shuffle } = Arcade;
         Arcade.game({
           /*THEME*/ home: 'indexpro.html', tag: '…', deco: [6 emojis], font: 'round|serif|mono|impact|comic|wide|fancy',
           bg: ['#claro', '#oscuro'], music: { mode: 'major|minor|dorian|lydian|mixo|harm|phryg', bpm, wave, style, root },
           voice: {…}, ambient: {…opcional},
           en: { title, tag, help, tvHelp, dict: { 'texto ES dibujado en canvas': 'EN' } },
           tvHelp: '…', tv: false | { mode: 'tap'|'swipe'|'drag', targets: (g) => [{x,y,w,h}] }  (sin tv = teclas),
           id, title, emoji, color, origin, help,
           lives: 3 (0 = sin vidas), levels: 0 (infinito), cap: 20–30,
           setup(g) {…g.s = estado…}, layout(g) {…recalcular geometría…},
           down/move/up/tap/swipe(g, p|dir), key(g, k, down), hover(g,x,y), update(g, dt), draw(g, ctx)
         });
       })();
   · API útil del motor: g.W g.H g.top g.bot g.lv (nivel con tope) g.level g.rt; g.addScore(n,x,y); g.win(estrellas?)
     (sin argumento calcula estrellas por vidas perdidas); g.die() → false si se acabó la partida; g.message(txt,t,sub);
     g.float, g.burst, g.ring, g.flash, g.shake, g.confetti, g.scenery; Arcade.emoji(ctx,e,x,y,size,{rot,alpha,flip,sx,sy});
     Arcade.txt(ctx,txt,x,y,size,color,align,peso,trazo); Arcade.rr (rect redondeado); Arcade.sfx.{coin,pop,hit,boom,win,
     lose,tick,move,up,bad,whoosh,combo(n)}; Arcade.tone(f,dur,onda,vol,slide); Arcade.T('es','en'); Arcade.lang.
   · Todo texto que se dibuja con Arcade.txt en español debe tener su traducción en en.dict (se traduce por fragmentos).
   · Protagonista: dibújalo con g.face() (cara que cambia sola; g.mood('scared') etc. para forzar). Enemigos: usa
     Arcade.FOES / Arcade.foe(n). Lo que se mueva, dibújalo con Arcade.emojiTo(ctx, e, x, y, tam, dx, dy) y, si el emoji
     es nuevo, añade hacia dónde mira en Arcade.FACING (common.js). El pad virtual 🎮 sale solo si el juego tiene key()
     o tv.targets (pad: false para quitarlo).
   · Demo: añade demo(g) que devuelva pasos ({ tap }, { drag }, { swipe }, { hold }, { key }, { wait }, con say/after);
     ver pwa/README.md («Demo automática»). Pruébala con el botón 👀 Ver demo: debería jugar con sentido y explicar
     la mecánica con 1–3 frases cortas.
   · Para reiniciar nivel tras perder vida: setTimeout(() => { if (g.state==='play' && g.die()) Arcade.current.def.setup(g); }, 1200).

2) Registrar y construir
   · Añadir la descripción en herramientas/mkgames.py (diccionario D: id → (desc ES, control ES, desc EN, control EN,
     tv: 'cruceta'|'cursor'|False)) y el id al principio de la lista PRO.
   · cd herramientas && python3 mkgames.py      → reescribe GAMES_PRO en pwa/games.js
   · python3 mk.py id1 id2 …                    → crea pwa/<id>.html
   · Subir ARCADE_VERSION en pwa/games.js (p. ej. 2.5.0) para que la PWA se actualice en los móviles.
   · python3 ../pwa/build.py                     → regenera autonomos/ (todos los .html autónomos)
   · Añade el id del juego a su categoría en CAT (herramientas/mkdb.py) y, si es nuevo, a ADDED con la versión.
   · python3 mkdb.py                             → regenera data/arcade.sqlite (la web PHP lee de ahí)
   · node --check src/<id>.js para comprobar sintaxis.

3) Probar
   · Si Playwright no encuentra su Chromium (p. ej. en Claude Code en la nube) usa una copia de los scripts con
     p.chromium.launch(executable_path='/opt/pw-browsers/chromium') en lugar de "playwright install".
   · mk.py deja una carpeta herramientas/sueltos_sin_config/ (copias autónomas sin config.js): bórrala, no se usa.
   · python3 tall.py <carpeta_para_capturas> file://$(pwd)/../autonomos id1,id2   (táctil; crea shots/ antes)
   · python3 ttv.py id1,id2 <carpeta>                                              (TV, 1 y 2 jugadores)
   · python3 t8n.py <carpeta>   (editar NEWG con los ids) → avisa de textos en español en la versión inglesa
   · Para balance/solubilidad: require('./mock.js')(ruta_src) y simular con mkG(nivel) + DEF.update(g, 1/60).
   · Revisar las capturas: que se vea bien en vertical (390×780) y en TV (960×540).

4) Publicar
   · Se trabaja directamente en la rama main (sin ramas).
   · GitHub Pages: sirve index.html (estático) → https://juliofuente.github.io/retrogames/
   · Hosting con PHP + Apache: sube todo el repositorio (index.php, .htaccess, data/, pwa/, autonomos/). Necesita
     mod_rewrite y la extensión pdo_sqlite. Si va en una subcarpeta y las URLs fallan, activa RewriteBase en .htaccess.
     Después, da de alta https://tudominio/sitemap.xml en Google Search Console.
